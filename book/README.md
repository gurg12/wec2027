## The six strings (score each separately)

1. **Energy** — chokepoint decade → electricity as the binding commodity (~2030) → engineered abundance (~2045+)
2. **Money** — eroding central-bank independence → fiscal dominance → nominal-heavy world → re-anchoring in the 2040s
3. **AI capability** — compounds through hype crashes; robotics ~5–7 years behind cognition
4. **AI politics** — permission collapses before displacement; bifurcation; thaw via medicine (~2031+)
5. **Order** — US spends hegemonic capital fast; middle powers load-bearing; tripolar-plus by ~2045
6. **The real** — machine traffic majority (~2027) → synthetic majority (~2033) → provenance + verified-human premium
